## Description

**Issue: Max Blog/Copywriter Flow Creates Too Much Friction + Misses Existing Instructions**
### Goal
I want to generate a **complete blog in one go** without needing multiple follow-up prompts or answering repetitive setup questions—especially when the AI already has prior instructions/context.
### Current Workflow Issue
I use Max to create **comparison blogs** with a **consistent structure** and predefined requirements.
My standard requirements are:
*   Consistent blog template:
    *   Main content
    *   Soft CTA
    *   5 short FAQs
    *   Final thoughts section
*   Blog angle:
    *   Position **Prosperna as the alternative/solution** to the problem or comparison topic.
However, Max still asks repetitive setup questions such as:
*   Blog format
*   Writing style
*   Target audience
*   Tone
*   Blog length
After answering these, it generates an outline but often **forgets the initial instruction to integrate Prosperna into the blog**, which is a key requirement.
### Comparison to Claude
In Claude, once the prompt/context is established, it:
*   Generates the **full blog directly**
*   Follows the expected structure consistently
*   Retains the instruction to position Prosperna within the content
*   Uses **web search** to improve accuracy, credibility, and freshness of facts/statistics
### Suggestions / Feature Requests
1. **Web Search Integration**
    *   Add a web search capability so blogs can include updated facts, statistics, and more credible information.
2. **Preset / Memory for Blog Preferences**
    *   Allow users to save preset blog instructions (e.g., tone, structure, audience, CTA format, Prosperna positioning).
    *   This would reduce repetitive questioning and allow faster one-shot blog generation.
### Expected Outcome
The goal is for Max to generate a **complete, structured blog in a single prompt**, while consistently following previously established blog requirements without needing repeated clarification.
