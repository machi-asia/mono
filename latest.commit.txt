feature(components): design system with themed layout primitives

- components: added token-based design system (`tokens.css`) as CSS custom properties — dark-primary with gold accents, with a light variant derived from the same tokens; shared spacing/easing/duration scales.
- components: added `ThemeProvider` (wraps `next-themes`) for SSG-safe theme switching (class attribute, system-preference support, dark default).
- components: added layout primitives `Row`, `Col`, `Card` consumed strictly from the package; apps must not hand-roll layout/functional elements.
- components: new exports (`ThemeProvider`, `Row`, `Col`, `Card` + props) and `next-themes` dependency; added `Row`/`Col`/`Card` and `ThemeProvider` tests (all components tests pass — 17).
- docs: live interactive showcase entries for `ThemeProvider`, `Row`, `Col`, `Card` (prop dropdowns) in `apps/docs/src/app/components/components/`; docs app depends on `next-themes`.
- docs: design-system conventions documented in `DESIGN.md` (Color & Theme, Motion, Spacing & Minimal Clutter, Component Rules, Content Density), `AGENTS.md` rule 13, `CONTRIBUTING.md`, `README.md`, `docs/ARCHITECTURE.md`, and new `docs/adr/005-design-system-theming.md`; `CHANGELOG.md` 0.6.0.
